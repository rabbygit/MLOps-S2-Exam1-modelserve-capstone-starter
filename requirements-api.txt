# Runtime deps for the FastAPI inference image.
#
# Trimmed subset of requirements.txt. The host venv keeps the full set
# (mlflow server, pytest, etc.) for training, debugging, tests. The
# container only carries what the API process imports at runtime.
#
# Trimmed:
#   mlflow → mlflow-skinny    drops alembic, sqlalchemy, flask, gunicorn-server, gitpython (~150 MB)
#   boto3                     transitive of full mlflow; we use the MLflow HTTP artifact proxy
#   psycopg2-binary           API talks to MLflow over HTTP, never to Postgres directly
#   pytest, httpx             test-only
